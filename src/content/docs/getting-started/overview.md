## Getting started with UDS Core

Use this section to get from zero to a working UDS Core environment.

There are two main paths:

- **Local demo (quickstart)** – start with a disposable cluster for evaluation.
  See [Local demo quickstart](/getting-started/local-demo/).
- **Production deployments** – plan and run a real deployment of UDS Core.
  See [Production deployments](/getting-started/production/).
